## MODIFIED Requirements

### Requirement: Marriage Processing During Tick

Settlement entities SHALL evaluate marriages during each tick.

#### Scenario: Marriage check

- **WHEN** a settlement entity ticks for a year
- **THEN** after role vacancy checks, the entity SHALL call `CheckMarriages` on its figures
- **THEN** any marriage events SHALL be emitted with the current year and settlement name

#### Scenario: Marriage age gate

- **WHEN** `CheckMarriages` evaluates figures
- **THEN** only unmarried figures aged 20–25 in the same faction SHALL be eligible

### Requirement: Role Transition Processing During Tick

Settlement entities SHALL evaluate role transitions after role event generation.

#### Scenario: Transition check

- **WHEN** a settlement entity ticks for a year
- **THEN** role events generated by figures SHALL be collected first
- **THEN** `CheckTransitions` SHALL be called with the generated events
- **THEN** any transition events SHALL be emitted with the current year and settlement name
- **THEN** the original role events SHALL be emitted after transition events

### Requirement: Updated Tick Order

The settlement tick order SHALL include marriage and transition checks.

#### Scenario: Full tick order

- **WHEN** a settlement entity ticks for a year
- **THEN** figure processing SHALL occur in the following order:
  1. Age figures (no-op, age is computed dynamically)
  2. Check deaths
  3. Check births
  4. Check role vacancies
  5. Check marriages
  6. Generate role-specific events
  7. Check role transitions
  8. Run settlement agent decision loop

### Requirement: Figure-Aware Narrative Selection

The simulation command SHALL prefer figure-aware grammar rules for Conflict, Politics, and Discovery events when figure context is available.

#### Scenario: Figure-aware narration

- **WHEN** a Conflict, Politics, or Discovery event has a non-empty `FigureID` and the figure is found
- **THEN** the narrative engine SHALL attempt `NarrateWithRule` using the `Category.figure` rule
- **THEN** if the figure-aware rule resolves, that text SHALL be printed
- **THEN** if the figure-aware rule fails, the base category rule SHALL be used

#### Scenario: Non-figure event narration

- **WHEN** a Conflict, Politics, or Discovery event has no figure context
- **THEN** the narrative engine SHALL use the base category rule directly
